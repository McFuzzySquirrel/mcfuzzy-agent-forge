# Quality Baseline

> Load when: Starting the workflow and before writing any proposal.

Use these standards for all collected evidence and all proposed checks.

## Evidence standard

1. Treat agentskills.io as the primary source for latest best-practice guidance.
2. Capture a citation URL for every proposed rule.
3. Capture one short quote or precise paraphrase per citation.
4. Record a recency signal (updated date or equivalent freshness marker) when available.

## Confidence tiers

- **High:** Directly stated best practice, clear language, no conflicting guidance found.
- **Medium:** Guidance is suggestive, partially scoped, or needs interpretation for rubric fit.
- **Low:** Ambiguous wording, conflicting source statements, or insufficient evidence detail.

## Output contract

Every proposed check must include:

- Rule title
- Target rubric axis (one of six)
- Evidence citation(s)
- Gap statement versus current skill-review
- Acceptance criteria (what makes the check pass/fail)
- Confidence tier

## Six-axis mapping guardrail

Only map proposals to these axes:

1. Context economy
2. Gotchas coverage
3. Procedural clarity
4. Progressive disclosure
5. Calibration
6. Validation
