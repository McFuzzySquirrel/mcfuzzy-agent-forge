# Validation Checks

> Load when: Any Step 6 completeness check fails or proposal confidence is unclear.

## Completeness diagnostics

1. Verify each proposal has a citation and acceptance criteria.
2. Verify each proposal maps to one primary axis.
3. Verify each "new" proposal includes an explicit baseline non-coverage statement.
4. Verify deferred items include a recheck trigger and reason.

## Failure patterns and fixes

- **Missing citation links.** Re-open Step 2 evidence collection and attach at least one direct source per proposal.
- **Axis drift.** Re-map the proposal to one primary axis using the six-axis guardrail and move secondary effects to notes.
- **Unclear acceptance criteria.** Rewrite checks into pass/fail language using observable artifacts.
- **Overconfident recommendation.** Lower confidence and move to conditional candidate unless evidence is unequivocal.
