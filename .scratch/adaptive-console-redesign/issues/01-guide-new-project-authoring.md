# 01: Guide a new Project through Idea authoring

**What to build:** A basic user can start with an Idea, move through interactive
Idea exploration and Project-brief authoring, and reach a review-ready brief.
The Project workspace and authoring progress remain resumable.

**Blocked by:** None (can start immediately).

**Status:** in_progress

- [ ] Starting from the primary Home action creates a resumable Project
  workspace without requiring technical setup first.
- [ ] The user can begin with an Idea, leave nonessential details unknown, and
  return to the last saved authoring step.
- [ ] Idea exploration and Project-brief authoring are clearly marked
  interactive phases; neither is headless or silently skipped.
- [ ] The user gets a suggested, editable Project name and a plain-language
  AI coding tool choice. The configured default is selected; if none exists,
  the user must choose explicitly.
- [ ] Detailed authoring runner/model, concurrency, and other technical
  controls stay outside the Basic path.
- [ ] A completed authoring session leaves a review-ready Project brief with
  assumptions and open questions visible.
- [ ] The user can leave for the supported authoring session and return to the
  same Project and guided step.
- [ ] Affected Console documentation and visual captures reflect the delivered
  flow.
