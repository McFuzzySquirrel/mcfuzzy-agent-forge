# 04: Give reviewers a focused Human review queue

**What to build:** A basic user can find and complete the Project Tasks that
need human judgment without navigating the full technical Task table.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] The Basic Tasks destination focuses on Human review items and explains
  why each review is ready or waiting.
- [x] Each review exposes its Task-specific criteria, references, blocker, and
  next responsible action.
- [x] A reviewer can record findings and explicitly approve through the
  existing Task-bound evidence contract.
- [x] The queue distinguishes a Human review from Project brief approval and
  does not imply that an agent or unattended flag can approve it.
- [x] Review state and Project context remain clear after approval or when the
  review is blocked.
- [x] Affected Console documentation reflects the delivered queue. At ticket
  04 implementation, the capture harness only supported regenerating the full
  set, so captures were not refreshed then. The harness later gained Board-only
  capture support, and the full set was refreshed with later tickets.
