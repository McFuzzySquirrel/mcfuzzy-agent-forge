# 04: Give reviewers a focused Human review queue

**What to build:** A basic user can find and complete the Project Tasks that
need human judgment without navigating the full technical Task table.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The Basic Tasks destination focuses on Human review items and explains
  why each review is ready or waiting.
- [ ] Each review exposes its Task-specific criteria, references, blocker, and
  next responsible action.
- [ ] A reviewer can record findings and explicitly approve through the
  existing Task-bound evidence contract.
- [ ] The queue distinguishes a Human review from Project brief approval and
  does not imply that an agent or unattended flag can approve it.
- [ ] Review state and Project context remain clear after approval or when the
  review is blocked.
- [ ] Affected Console documentation and visual captures reflect the delivered
  queue.
