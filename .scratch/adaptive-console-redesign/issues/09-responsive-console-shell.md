# 09: Adapt the Console shell to wide, medium, and narrow layouts

**What to build:** Users can navigate the adaptive Console and retain Project
context on wide, medium, and narrow screens.

**Blocked by:** 08: Organize navigation around Project goals and Advanced.

**Status:** ready-for-agent

- [ ] The shell starts with content-driven ranges of wide above 1050px, medium
  from 721–1050px, and narrow at 720px or below; adjust only when content
  requires it.
- [ ] Wide screens show the full navigation, medium screens use a compact
  navigation rail, and narrow screens use a labeled drawer or menu.
- [ ] Home, Projects, the Project switcher, primary Project destinations, and
  Advanced destinations remain discoverable in every layout.
- [ ] The context bar adapts without obscuring Project identity, switching, or
  status information.
- [ ] Layout changes preserve the active destination and Project context.
- [ ] Affected Console documentation and visual captures reflect the delivered
  layouts.
