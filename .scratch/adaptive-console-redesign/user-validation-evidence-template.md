## Session protocol

- Use the actual Console with deterministic fixture Projects and stubbed
  authoring and launcher processes.
- Give the participant the scenario goal, but do not coach or explain controls.
- There is no arbitrary time limit. Record whether the participant completes
  each applicable scenario without facilitator help.
- Mark a scenario N/A only when it genuinely does not apply to this participant;
  include the reason.
- Any critical lifecycle, Project-context, or accessibility failure blocks
  acceptance.
